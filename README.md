# 友情ブレイカーズ ― 3D乱闘パーティー

拳で殴り合い、掴んで、投げて、相手を場外に落とせば勝ち。スキルや状態異常で何でもアリの友情破壊ゲーム。

**▶ 遊ぶ：** このリポジトリの GitHub Pages（Settings → Pages に表示されるURL）を Chrome / Edge で開く

- CPU戦、オンライン対戦（部屋コードで最大8人）、チーム戦
- マップ6種類（開始時に投票）
- ルール説明と技の動画つき、キー割り当て・感度などの設定画面

操作やルールの詳しい説明は [遊び方.txt](遊び方.txt) とゲーム内の「ルール説明」を見てください。

## 仕組み
- 3D描画：[Three.js](https://threejs.org/) r149（MIT）
- オンライン対戦：[PeerJS](https://peerjs.com/) 1.5.4（MIT）によるブラウザ同士の直接通信。ホストのブラウザがゲームを計算します。ゲーム用のサーバーは不要です。
- `LANサーバー/` は同じWi-Fiで遊ぶための任意のサーバーです（GitHub Pagesでは使いません）。
